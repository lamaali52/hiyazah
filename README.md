# حيازة

**منصة تفعيل الأصول الموروثة المعطلة**
فريق أثر · هاكاثون رُوّاد (برمجان) · بريدة، أكتوبر ٢٠٢٦
المسار: الابتكار الحكومي والتحول الذكي

---

## المشكلة

الأصل الموروث المشاع — زراعياً كان أو سكنياً أو تجارياً — يبقى معطلاً سنوات، لأن ملكيته تتفتت بين ورثة لا تكفي حصة أيٍّ منهم للاستثمار منفرداً، والقسمة تأخذ سنوات. فلا يُشغَّل الأصل ولا يُسيَّل.

- في الأصول الزراعية، التعطيل **يأكل الأصل**: البئر يتوقف، والنخل ييبس، والقيمة تنخفض كل سنة.
- في الأصول السكنية والتجارية، التعطيل **يحبس السيولة**: الحصة المشاعة لا تُباع بسعر السوق.
- ولا توجد جهة تعرف حجم الظاهرة: كم أصلاً معطلاً، من أي نوع، ولأي سبب.

## الحل

1. **الدمج التعاقدي** — تجمع المنصة القطع والحصص المتجاورة في كتلة استثمارية واحدة تتجاوز حد جدوى المشغّل، باستخدام نظم المعلومات الجغرافية (GIS). التجميع يقع في العقد لا في الصك، فكل وريث يحتفظ بملكيته كما هي.
2. **التوزيع المحسوب** — يحسب النظام نصيب كل وريث من العائد حسب الأنصبة المستمدة من صك حصر الإرث، والصرف عبر مزوّد دفع مرخّص.
3. **الرصد والتصنيف** — لوحة للجهة الحكومية ترصد الأصول المعطلة في نطاقها، مصنفة بنوع الأصل وسبب التعطل، وتقيس القيمة الاقتصادية المتوقعة من تفعيلها.

> لا نملك الأرض، ولا نزرعها، ولا نمس صكوكها. نحن طبقة التعاقد والتوزيع والرصد التي تجعل الأصل المشاع قابلاً للتشغيل.

## النموذج الأولي

ثلاث شاشات في صفحة واحدة:

| الشاشة | ما تعرضه |
|---|---|
| لوحة الرصد | ١٨ أصلاً معطلاً موزعة على محافظات منطقة القصيم، على خريطة فضائية، مع فلترين: نوع الأصل وسبب التعطل |
| الدمج | ست قطع متجاورة في بساتين النخيل القديمة المتجزئة جنوب غرب عنيزة؛ اختيارها يجمع المساحة ويقارنها بحد الجدوى، مع مقارنة قبل الدمج وبعده، ثم تتكوّن الكتلة |
| توزيع العائد | حاسبة أنصبة حيّة: غيّر تركيبة الورثة وتتغير المبالغ بالهللة |

### التشغيل

افتح `index.html` في المتصفح (يحتاج اتصال إنترنت للخريطة والخطوط)، أو عبر رابط GitHub Pages.

روابط مباشرة لكل شاشة: `#dashboard` · `#merge` · `#distribute`

### سيناريو العرض المقترح

1. **لوحة الرصد**: المنطقة كاملة — بريدة وعنيزة والرس والبكيرية والمذنب وغيرها. اضغط فلتر «سكني» ثم «تجاري» لإثبات أن المنصة تغطي كل الأنواع، ثم ارجع لـ«الكل».
2. **الدمج**: كتلة في بساتين عنيزة. اختر ٠٤٢ ثم ٠٤٦ ثم ٠٤٤ → «غير متجاورة». أضف ٠٤٣ → ٤٧٧٬٠٠٠ م² تتجاوز حد ٤٠٠٬٠٠٠ م² وتصبح خضراء. اضغط «تكوين الكتلة».
3. ارجع لـ**لوحة الرصد**: الأصول الأربعة صارت خضراء، والعدّاد نزل.
4. **توزيع العائد**: غيّر عدد الأبناء أمام اللجنة، والمجموع يبقى مطابقاً بالهللة.

### تعديل الأرقام

كل الأرقام في ملف `data.js`: الإيجار لكل م²، حد الجدوى، نسبة حيازة، والأصول. غيّر الرقم وتتحدث الشاشات كلها.

| الملف | الدور |
|---|---|
| `index.html` | الواجهة والتصميم |
| `data.js` | البيانات والافتراضات |
| `calc.js` | حساب الأنصبة والتجاور (بدون اعتماد على الصفحة) |
| `app.js` | منطق الشاشات والخرائط |
| `docs/` | مستندات العرض |

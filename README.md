# حيازة

**محرك تفعيل الأصول العقارية المعطلة**
فريق أثر · هاكاثون رُوّاد (برمجان) · بريدة، أكتوبر ٢٠٢٦
المسار: الابتكار الحكومي والتحول الذكي

---

## المشكلة

الأصل العقاري المعطل — أرضاً بيضاء كان أو مبنى قديماً أو مستودعاً أو زراعياً — يبقى معطلاً سنوات، لأن ملكيته تتفتت بين ورثة لا تكفي حصة أيٍّ منهم للاستثمار منفرداً، والقسمة تأخذ سنوات. فلا يُشغَّل الأصل ولا يُسيَّل.

- في الأصول الزراعية، التعطيل **يأكل الأصل**: البئر يتوقف، والنخل ييبس، والقيمة تنخفض كل سنة.
- في الأصول السكنية والتجارية، التعطيل **يحبس السيولة**: الحصة المشاعة لا تُباع بسعر السوق.
- ولا توجد جهة تعرف حجم الظاهرة: كم أصلاً معطلاً، من أي نوع، ولأي سبب.

## الحل

1. **الدمج التعاقدي** — تجمع المنصة القطع والحصص المتجاورة في كتلة استثمارية واحدة تتجاوز حد جدوى المشغّل، باستخدام نظم المعلومات الجغرافية (GIS). التجميع يقع في العقد لا في الصك، فكل وريث يحتفظ بملكيته كما هي.
2. **التوزيع المحسوب** — يحسب النظام نصيب كل وريث من العائد حسب الأنصبة المستمدة من وثيقة حصر الورثة الصادرة عبر ناجز. المشغّل يدفع لكل مالك حصته مباشرة، وحيازة لا تستلم الأموال.
3. **الرصد والتصنيف** — لوحة للجهة الحكومية ترصد الأصول المعطلة في نطاقها، مصنفة بنوع الأصل وسبب التعطل، وتقيس القيمة الاقتصادية المتوقعة من تفعيلها.

> لا نملك الأرض، ولا نزرعها، ولا نمس صكوكها. نحن طبقة التعاقد والتوزيع والرصد التي تجعل الأصل المشاع قابلاً للتشغيل.

## النموذج الأولي

أربع شاشات في صفحة واحدة، شاشة لكل فئة مستفيدة:

| الشاشة | ما تعرضه |
|---|---|
| لوحة الرصد | ١٨ أصلاً معطلاً موزعة على محافظات منطقة القصيم، على خريطة فضائية، مع فلترين: نوع الأصل وسبب التعطل |
| الدمج | ست قطع أرض بيضاء متجاورة في مخطط جديد شمال بريدة؛ اختيارها يجمع المساحة ويقارنها بحد جدوى المطور، ثم تتكوّن الكتلة ويظهر العقد الموحد وإيراد المنصة |
| فرص الاستثمار | للمطور والمشغّل: الكتل الجاهزة للتأجير، بعقود بشروط متطابقة لكل صك يوثّقها شريك مرخّص عبر شبكة إيجار |
| بوابة الملاك | للمالك والوريث: الأنصبة من وثيقة حصر الورثة (ناجز) محسوبة من الإيجار كاملاً، وحالة موافقة كل وريث. المشغّل يدفع لكل مالك حصته مباشرة — حيازة لا تستلم الأموال |

### التشغيل

افتح `index.html` في المتصفح (يحتاج اتصال إنترنت للخريطة والخطوط)، أو عبر رابط GitHub Pages.

روابط مباشرة لكل شاشة: `#dashboard` · `#merge` · `#invest` · `#owners`

### سيناريو العرض المقترح

1. **لوحة الرصد**: المنطقة كاملة — بريدة وعنيزة والرس والبكيرية والمذنب وغيرها. اضغط فلتر «أرض بيضاء» ثم «زراعي» لإثبات أن المنصة تغطي أكثر من نوع، ثم ارجع لـ«الكل».
2. **الدمج** (بريدة): اختر ٠٤٢ ثم ٠٤٦ ثم ٠٤٤ → «غير متجاورة». أضف ٠٤٣ → ١٢٬٠٠٠ م² تتجاوز حد الجدوى (١١٬٠٠٠ م²) وتصبح خضراء: «٠ ر.س لقطعة معطلة ← ١٨٠٬٠٠٠ ر.س إيجار سنوي ككتلة». الإيجار يدفعه المشغّل للملاك مباشرة ولا يمر عبر المنصة. إيراد حيازة على مرحلتين: المرحلة ١ (نموذج أولي) رسم ثابت ١٠٬٠٠٠ ر.س لكل كتلة يدفعه المطور (مقترح)، والمرحلة ٢ (بعد الترخيص) عمولة ٤٬٥٠٠ + إدارة ٩٬٠٠٠ = ١٣٬٥٠٠ ر.س في السنة الأولى ثم ٩٬٠٠٠ سنوياً. اضغط «تكوين الكتلة».
3. ارجع لـ**لوحة الرصد**: الأصول الأربعة صارت خضراء، والعدّاد نزل.
4. **فرص الاستثمار**: الكتلة التي تكوّنت تظهر بطاقةً جاهزة للتأجير.
5. **بوابة الملاك**: غيّر عدد الأبناء أمام اللجنة، والمجموع يبقى مطابقاً بالهللة. لاحظ الوريث القاصر «بانتظار الإذن النظامي».

### تعديل الأرقام

كل الأرقام في ملف `data.js`: أنواع الأصول وأسباب التعطل، الإيجار لكل م²، حد الجدوى، رسم الكتلة في المرحلة ١ (١٠٬٠٠٠ ر.س، مقترح)، وعمولة الوساطة (٢٫٥٪) ورسم إدارة الأملاك (٥٪ سنوياً) في المرحلة ٢، والأصول. غيّر الرقم وتتحدث الشاشات كلها.

| الملف | الدور |
|---|---|
| `index.html` | الواجهة والتصميم |
| `data.js` | البيانات والافتراضات |
| `calc.js` | حساب الأنصبة والتجاور (بدون اعتماد على الصفحة) |
| `app.js` | منطق الشاشات والخرائط |
| `docs/` | مستندات العرض |
